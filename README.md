AHRI Call Dashboard Project

Project Overview



This project is a collaboration between the Australian HR Institute (AHRI) and Monash University to develop a Power BI dashboard for analysing Microsoft Teams telephony data.



The dashboard aims to provide AHRI with clear visibility into phone activity and help the Member Engagement team better understand call demand, caller routing, operational patterns, and call outcomes.



Project Objectives



The dashboard will analyse key call metrics including:



Total call volume

Daily, weekly, and monthly call trends

Answer rate

Abandon rate

Average wait time

Average talk time

IVR routing and destination

Calls by team or destination

Time-of-day patterns

Day-of-week patterns

Peak call periods



The initial scope focuses on historical and current-state reporting rather than real-time monitoring or SLA measurement.
